# PdfTeachAnnotator v1.2.0 发布说明

发布日期：2026-06-28

## 下载

推荐下载 GitHub Release 附件：

- `PdfTeachAnnotator-TesseractOnly-win-x64.zip`

解压后，双击根目录的 `PdfTeachAnnotator.exe` 即可启动。发布包根目录只保留一个启动程序，其余内容按用途放入文件夹：

```text
PdfTeachAnnotator.exe
App/
docs/
tools/
```

## 版本定位

v1.2.0 是面向课堂使用体验和稳定发布形态的一次更新。`main` 分支保持 Tesseract-only，默认使用本地 Tesseract OCR；PaddleOCR 实验方案保留在 `feature/paddleocr` 分支，便于后续单独验证模型、性能和包体积。

## 主要更新

### 现代化教学界面

- 重构主页、工具箱、设置页和关于页内容。
- 侧边栏支持折叠，折叠后只显示图标。
- 侧边栏折叠、页面切换加入平滑动画。
- 动态页码指示显示当前可见页和总页数。
- 关于页已改为 `PdfTeachAnnotator` 品牌文案，突出课堂批注、本地 OCR 和旁路保存。

### PDF 批注体验

- 支持钢笔、荧光笔、激光笔和橡皮擦。
- 支持 12 种预设颜色和多档工具尺寸。
- 支持撤销 / 重做。
- 批注保存为同名 `.annotations` 文件，不修改原始 PDF。
- 支持自动保存、手动保存和最近文件列表。

### 本地 OCR

- `main` 分支默认使用 `Tesseract 5.2.0`。
- 支持中文简体与英文识别：`chi_sim + eng`。
- 支持整篇 PDF 识别、页级进度显示和结果复制。
- OCR 处理在本地完成，不上传 PDF 或识别结果。

### 发布包结构

- 新发布包采用“根启动器 + App 完整应用目录”的稳定布局。
- zip 根目录只有一个 `PdfTeachAnnotator.exe`，方便普通用户运行。
- 完整 .NET 8 self-contained 应用保留在 `App/`，避免破坏 `.deps.json`、`.runtimeconfig.json`、PDFium、Tesseract 和 native DLL 的加载路径。
- `docs/` 放置说明文档，`tools/` 放置诊断工具。

## 修复

- 修复主页“浏览文件”按钮无法打开文件的问题。
- 修复侧边栏折叠后宽度过窄导致图标被遮挡的问题。
- 修复首次打开文档时页码显示不正确的问题。
- 修复主题切换时因冻结画刷导致的异常。
- 修复缺失右箭头图标资源导致应用无法启动的问题。

## 系统要求

- Windows 10/11 x64。
- 发布包为 self-contained，普通用户通常无需单独安装 .NET Runtime。
- OCR 原生组件可能需要 Visual C++ 2015-2022 x64 Runtime；若启动或 OCR 异常，可运行 `tools/诊断工具.bat` 检查。

## 升级建议

1. 下载并解压 `PdfTeachAnnotator-TesseractOnly-win-x64.zip`。
2. 双击根目录 `PdfTeachAnnotator.exe` 启动。
3. 旧版 `.annotations` 批注文件仍与原 PDF 同目录保存，可继续自动加载。
